Get started

Up in 60 seconds.

One binary, no cloud signup. Add to your editor's MCP config and every capability is immediately accessible.

Install & Initialize 
# Linux — prebuilt binary
curl -fsSL https://raw.githubusercontent.com/danieldear/agent007/main/scripts/install.sh | bash

# macOS — build from source
cargo install --git https://github.com/danieldear/agent007.git agent007

# Register with your editors & start server
agent007 init
agent007 serve
  ✓ MCP ready on stdio
  ✓ Dashboard → http://localhost:8007
  ✓ 50+ tools available
Register with your editor 
# Register with all installed editors at once
agent007 init

# Or target a specific editor
agent007 init --claude   # Claude Code
agent007 init --cursor   # Cursor
agent007 init --codex    # Codex CLI
agent007 init --copilot  # Copilot
agent007 init --zed      # Zed
Run your first skill 
# In Claude Code / Cursor / Codex / Copilot / Zed:
/agent007-dev-debug "API returning 500s on /auth/login"

# Or trigger the security audit workflow:
/agent007-workflow-security-audit "review login function"
