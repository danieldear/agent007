Performance · New

Zero-overhead tools.
Zero LLM tokens.

The Embedded Tool Runtime now exposes 26 built-ins at L1 speed — JSON query, joins, metrics, workflow health, log slicing, table selection, policy checks, and more with zero model round-trips.

⚡
<1ms latency — no round-trips
ETR tools execute in the same process as the MCP server. grep over 10,000 files in under a millisecond. No subprocess, no network, no waiting.
🪙
Zero token cost
ETR tools don't send prompts to a language model. Every file search, math operation, or diff runs in pure Rust. Your token budget stays where it belongs — on reasoning.
🔗
Same MCP interface, three layers
L1 = pure Rust native. L2 = sandboxed subprocess. L3 = LLM-backed. The dispatcher routes automatically — your AI just calls agent007_etr_call.
Using ETR from your editor 
# Search a codebase without burning tokens
agent007_etr_call("etr.grep", {
  "pattern": "fn build_stack",
  "path": "crates/"
})
# → results in 0.3ms · 0 tokens used

# Filter JSON and project only the fields you need
agent007_etr_call("etr.json_query_v2", {
  "path": "workflow-state.json",
  "query": ".steps[*]",
  "project": ["id", "status"],
  "limit": 5
})
# → deterministic structured output · 0 prompt tokens

Performance · New

Three tiers of token reduction.
Stack them all.

agent007 applies token reduction automatically at three independent layers. Each tier is additive — combine all three for maximum savings without changing your workflow.

Layer 1 — API
Prompt Caching
Injects Anthropic cache_control markers on repeated context blocks — system prompts, skill templates, large memory payloads. The API caches these blocks server-side so subsequent calls cost a fraction.
~40%
cost reduction on cached context
Layer 2 — Structural
Structural Minification
Pure Rust pre-processing: collapses blank lines, strips trailing whitespace, normalizes markdown headers. Applied before every LLM call. Lossless — no semantic changes. Zero quality impact.
15–25%
input token reduction
Layer 3 — Lazy Injection
Lazy Injection
Large intermediate outputs (step results, tool responses) are stored as artifacts and replaced with compact stubs. The next step receives the stub and retrieves the full artifact only if needed.
50–70%
savings on large intermediate outputs
Automatic — no config required

Get started

Three commands
and you're live.

Linux, Apple Silicon macOS, and Windows ship as release artifacts. Intel macOS falls back to source install. Dashboard assets are embedded in the binary — no separate frontend build.

Install 
# Linux x86_64 (prebuilt binary)
curl -fsSL https://raw.githubusercontent.com/danieldear/agent007/main/scripts/install.sh | bash

# Intel macOS (source install fallback)
cargo install --git https://github.com/danieldear/agent007.git agent007

# Local development
cargo install --path crates/cli
Quick start 
# Init — creates ~/.agent007/ and
# registers MCP with all editors
agent007 init

# Start MCP server + dashboard
agent007 serve

# Run a one-shot task
agent007 run "refactor auth to use JWT"
Target a specific editor 
agent007 init --claude   # Claude Code only
agent007 init --cursor   # Cursor only
agent007 init --copilot  # GitHub Copilot / VS Code
agent007 init --codex    # Codex CLI
agent007 init --zed      # Zed
agent007 init             # All of the above
Slash-like dispatch (Codex / any editor) 
agent007_dispatch command="$agent007 wf tdd add rate limiting"
agent007_dispatch command="$agent007 skill /brainstorm onboarding ideas"
agent007_dispatch command="$agent007 run refactor auth module"
