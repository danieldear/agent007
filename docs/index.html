Multi-agent

One task.
Many specialists.

Dispatch a task to a team of specialized AI workers that run in parallel, share results through shared memory, and report live to the dashboard — all without you managing the coordination.

⚡
Parallel execution
Workers run concurrently — a security review, a performance review, and a gap analysis all happen at the same time. The orchestrator collects and synthesizes.
🔄
Automatic recovery
If a worker gets blocked, the orchestrator reassigns or replans — without interrupting the other workers or tearing down the session.
🧠
Shared memory
Workers pass intermediate results through shared memory without explicit message passing. The final synthesis has access to everything every worker learned.
📡
Live on the dashboard
Every worker status, result, and block event flows to the live dashboard in real time. See exactly what each agent is doing — or not doing.

Get started

Up in 60 seconds.

One binary, no cloud signup, no configuration required to start. Add your editor's MCP config and every capability is immediately available.

Install 
# Install from crates.io
cargo install agent007

# Initialize your project
agent007 init

# Start the MCP server + dashboard
agent007 serve
  ✓ MCP server ready
  ✓ Dashboard → http://localhost:8007
  ✓ 50+ tools available
claude_desktop_config.json / .mcp.json 
{
  "mcpServers": {
    "agent007": {
      "command": "agent007",
      "args": ["mcp"]
    }
  }
}
