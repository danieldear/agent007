Performance · 26 built-ins

Zero-overhead tools.
Zero LLM tokens.

The Embedded Tool Runtime dispatches through three layers — L1 Rust native, L2 sandboxed subprocess, L3 LLM-backed. Your AI calls one interface; the dispatcher picks the fastest available layer automatically.

L1
Pure Rust native
In-process execution — no subprocess, no network. grep, json_query, metrics, workflow inspection, and 20+ more run here. Zero overhead.
< 1ms
0 tokens
L2
Sandboxed subprocess
Shell tools, scripts, and custom executables run in a sandboxed child process with controlled stdin/stdout. Used when native Rust isn't sufficient.
~10ms
0 tokens
L3
LLM-backed fallback
For tasks that genuinely require reasoning. Only reached when L1 and L2 cannot handle the request. Your token budget stays on what matters.
~1-3s
tokens used
Same interface, three layers

Performance · Automatic

Three tiers of token reduction.
Stack them all.

agent007 applies token reduction automatically at three independent layers. Each tier is additive — combine all three for maximum savings without any workflow changes.

Layer 1 — API
Prompt Caching
API-level caching
Injects Anthropic cache_control markers on repeated context blocks — system prompts, skill templates, large memory payloads. The API caches these blocks server-side so subsequent calls cost a fraction.
~40%
cost reduction on cached context
Layer 2 — Structural
Minification
Structural minification
Pure Rust pre-processing: collapses blank lines, strips trailing whitespace, normalizes markdown headers. Applied before every LLM call. Lossless — zero semantic change, zero quality impact.
15–25%
input token reduction
Layer 3 — Lazy Injection
Lazy Inject
Lazy artifact injection
Large intermediate outputs are stored as artifacts and replaced with compact stubs. The next step retrieves the full artifact only if needed, slashing context size for long workflows.
50–70%
savings on large intermediate outputs
Automatic — zero config

Milestone 6 · Structural Intelligence

Your repo is now
a first-class data source.

agent007 builds a persistent structural graph of your codebase — files, symbols, imports, call chains, and doc links — and exposes it through ETR tools so your AI retrieves real structure instead of guessing from context.

🗂️
Persisted repo_graph_v1.json
Built once at agent007 init and refreshed incrementally. Stored in .agent007/runtime/ alongside session state and vector indexes. Staleness detection surfaces when your graph needs a rebuild.
🔍
Symbol lookup · caller graph
Use etr.symbol_lookup to find where any function, struct, or trait is defined, and etr.callers to trace who calls it — without burning tokens on a grep chain.
📝
Doc → symbol links
Markdown files are parsed for symbol mentions. Two-pass build ensures doc nodes are linked against a complete symbol index — README.md and docs/ are always fully resolved.
🚀
Graph-aware ETR queries
All graph ETR tools run at L1 — the graph is loaded into memory and queried in pure Rust. etr.graph_status shows counts, build time, and stale file count at a glance.

Get started

Three commands
and you're live.

Linux, Apple Silicon macOS, and Windows ship as release artifacts. Intel macOS falls back to source install. Dashboard assets are embedded in the binary — no separate frontend build required.

Install 
# Linux x86_64 (prebuilt binary)
curl -fsSL https://raw.githubusercontent.com/danieldear/agent007/main/scripts/install.sh | bash

# Intel macOS (source install fallback)
cargo install --git https://github.com/danieldear/agent007.git agent007

# Local development
cargo install --path crates/cli
Quick start 
# Init — creates ~/.agent007/ and
# registers MCP with all editors
agent007 init

# Start MCP server + dashboard
agent007 serve

# Run a one-shot task
agent007 run "refactor auth to use JWT"
Target a specific editor
agent007 init --claude   # Claude Code only
agent007 init --cursor   # Cursor only
agent007 init --copilot  # GitHub Copilot / VS Code
agent007 init --codex    # Codex CLI
agent007 init --zed      # Zed
agent007 init             # All of the above
Slash-like dispatch (Codex / any editor)
agent007_dispatch command="$agent007 wf tdd add rate limiting"
agent007_dispatch command="$agent007 skill /brainstorm onboarding ideas"
agent007_dispatch command="$agent007 run refactor auth module"
