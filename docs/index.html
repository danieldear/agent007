Multi-agent

One task.
Many specialists.

Dispatch to a team of specialized AI workers running in parallel, sharing results through memory, reporting live to the dashboard — all without manual coordination.

⚡
True parallelism
Workers run concurrently — security, performance, and gap analysis all happen at the same time. Orchestrator collects and synthesizes results.
🔄
Automatic recovery
If a worker hits a blocker, the orchestrator reassigns without interrupting other workers or tearing down the session.
🧠
Shared memory synthesis
Workers share intermediate results through memory without explicit message passing. The final synthesis has everything every worker learned.

Get started

Up in 60 seconds.

One binary, no cloud signup. Add to your editor's MCP config and every capability is immediately accessible.

Install & Initialize 
# Install from crates.io
cargo install agent007

# Initialize your project
agent007 init

# Start the MCP server + dashboard
agent007 serve
  ✓ MCP ready on stdio
  ✓ Dashboard → http://localhost:8007
  ✓ 50+ tools available
Editor config (.mcp.json) 
{
  "mcpServers": {
    "agent007": {
      "command": "agent007",
      "args": ["mcp"]
    }
  }
}
