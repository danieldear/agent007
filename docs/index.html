Get started

Install paths,
clearly defined.

Linux x86_64 ships as a prebuilt release artifact via curl installer. macOS currently installs from source, and cargo install now builds dashboard assets automatically.

Install 
# Linux x86_64 (prebuilt release artifact)
curl -fsSL https://raw.githubusercontent.com/danieldear/agent007/main/scripts/install.sh | bash

# macOS (source install)
cargo install --git https://github.com/danieldear/agent007.git agent007

# Local development install
cargo install --path crates/cli
Quick start 
# 1. Init — creates ~/.agent007/ and
#    registers MCP with all editors
agent007 init

# 2. Start MCP server + dashboard
agent007 serve

# 3. Or run a one-shot task
agent007 run "refactor auth to use JWT"

Current release automation publishes Linux artifacts only to keep pipeline time low. CI and release runners are Linux-based for now; macOS uses source install until prebuilt artifacts are reintroduced.

Source installs (`cargo install --git ...` or local cargo install) auto-build the frontend and embed the dashboard bundle in the binary, so agent007 serve works without a separate frontend build step.

Codex command-style usage 
# Slash-like command routing through one MCP tool
agent007_dispatch command="$agent007 wf tdd add rate limiting to API"
agent007_dispatch command="$agent007 skill /brainstorm onboarding ideas"
agent007_dispatch command="$agent007 run refactor auth module"
Pick your editor 
agent007 init --claude   # Claude Code only
agent007 init --cursor   # Cursor only
agent007 init --copilot  # GitHub Copilot / VS Code
agent007 init --codex    # Codex CLI
agent007 init --zed      # Zed
agent007 init             # All of the above at once

Pipelines

Workflows that ship.

YAML pipelines with parallel step execution, approval gates, and full run history. Run from your editor or the CLI.

Running a workflow
agent007_dispatch command="$agent007 wf code-review review src/auth.rs"
agent007 workflow run code-review "review src/auth.rs"
agent007 workflow run tdd "add rate limiting to the API"
agent007 workflow run feature "build export to CSV"
Workflow Steps Use for
tdd 3 Red → Green → Refactor cycle parallel
code-review 4 Security + performance + style in parallel, synthesized
sparc 5 Spec → Pseudocode → Architecture → Refinement → Completion
feature 17 Full delivery: spec → arch → implement → review → test → release
log-analysis 4 Error analysis + pattern detection + security check
security-audit 5 OWASP + secrets + threat model + dependencies in parallel
ideation 7 Research → PRD → architecture → project milestones
