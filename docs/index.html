True parallelism

Multiple workers run concurrently — security audit while tests are generating, research while code is being written. No waiting.

🧠
Shared memory, no repetition

Every agent reads from and writes to the same memory store. One agent's finding is instantly available to every other agent in the run.

📊
Dispatches · collects · synthesizes

The orchestrator breaks tasks down, assigns to specialists, collects results, resolves conflicts, and delivers a synthesized output.

🔒
Persona-scoped capabilities

Each worker runs under its own persona — its own model, memory namespace, and allowed tool set. No agent can exceed its defined scope.

Get started

Running in 60 seconds.

Install via Homebrew or Cargo, then add the MCP config to your editor.

macOS — Homebrew
brew install agent007
Cargo — All platforms
cargo install agent007
MCP config — Claude Code / Cursor / Zed
{
  "mcpServers": {
    "agent007": {
      "command": "agent007",
      "args": ["mcp"]
    }
  }
}
