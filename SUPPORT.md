# Support

## Community and Usage Help

Use GitHub Discussions for questions, setup help, and usage guidance.

## Bug Reports

Open a GitHub Issue with:

- environment details
- reproduction steps
- expected vs actual behavior
- logs or screenshots when available

## Security Issues

Do not file security issues publicly. Follow `SECURITY.md`.

## Response Expectations

This is currently maintained as a fast-moving startup-style project. Best effort
support is provided, with priority to release blockers, regressions, and data-loss risks.
